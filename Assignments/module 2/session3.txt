(B) Create a constant variable to store the GST rate (for example, 18%) and use it to calculate the final price of a Zomato order with a given base price.<br><br><em><strong>Constraint:</strong> The GST rate must not be changeable after its initial assignment.</em>

 ->     #include <stdio.h>
	#include <conio.h>

	void main()
	{
          const float GST_RATE = 18.0;   // Constant GST rate (18%)
    	  float basePrice = 500.0;
   	  float gstAmount, finalPrice;

          gstAmount = (basePrice * GST_RATE) / 100;
    	  finalPrice = basePrice + gstAmount;

   	  printf("Base Price: Rs. %.2f\n", basePrice);
    	  printf("GST Rate: %.0f%%\n", GST_RATE);
    	  printf("GST Amount: Rs. %.2f\n", gstAmount);
   	  printf("Final Price: Rs. %.2f\n", finalPrice);

   	 getch();
        }

(D) Identify and correct the invalid variable names from this list: 1stPlayer, player_age, $score, total-marks, userName.<br><br><em><strong>Hint:</strong> Apply standard variable naming rules for your programming language.</em>

   ->   1.1stPlayer → Invalid
	  Variables cannot start with a number.
     	  Correct: firstPlayer or player1
	2.$score → Invalid
	  $ is not allowed in standard variable names (in C/Java).
 	  Correct: score
	3.total-marks → Invalid
	Hyphen - is treated as subtraction operator.
 	Correct: totalMarks or total_marks

   ->  Valid variable names
      1. player_age → Valid (underscore allowed)
      2. userName → Valid (camelCase allowed)
